# AC Transporte — Site

## Como abrir
1. Extraia o ZIP.
2. Abra `index.html` no Chrome.
3. Não precisa de servidor para testar a interface.

## WhatsApp

**(11) 96156-6639**

## E-mail
Como nenhum e-mail comercial foi enviado, o site deixou um placeholder:
`SEU_EMAIL_AQUI`

No `index.html`, procure por `SEU_EMAIL_AQUI` e troque pelo e-mail real.

## Cadastro
A área de cadastro funciona no navegador usando `localStorage`. Isso é ótimo para uma demonstração/site estático, mas não é um sistema de cadastro online real.

Para ter cadastro real com banco de dados, login, painel administrativo e envio de e-mails, é necessário adicionar um backend (por exemplo, Node.js + banco de dados).

## Identidade visual
O layout foi criado do zero inspirado na arte enviada: preto, branco, laranja/vermelho, tipografia forte, veículos, São Paulo e comunicação direta.
